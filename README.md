# DigiCron — versões

Aqui ficam só as versões publicadas do DigiCron (cronômetro de estúdio da Digicast). O código-fonte não fica neste repositório.

O app procura atualizações aqui e só instala quando o usuário confirma. Cada versão é assinada digitalmente, e o app recusa qualquer arquivo sem a assinatura certa.
